# Comparison of JMP and Python graph
The JMP visualisation is strong because it shows almost everything at once: the individual 
data points, the boxplots, and the overall spread of the distributions. This makes it very 
useful for exploring the data in depth and for checking assumptions like skewness, 
variability, and the presence of extreme values. You can clearly see how the summaries 
relate to the raw data. The limitation I see in JMP Graph is that the labels are not in the 
correct position. That can make the reader confused about the mean values. 
The baseline Python visualisation, on the other hand, focuses more on clarity and 
storytelling. The downside is that it hides some of the detail in the raw data, so you have to 
trust the summary statistics more. From the AI prompts, the Python graph started to show 
outliers, although that was not in the standard way. And according to the next AI prompt Python
graph, I was able to show data labels in the boxplot graph. 
For a final report or presentation, I would choose the JMP visualisation because it 
communicates the main message clearly and efficiently, while the JMP plot is better suited 
for behind-the-scenes analysis rather than audience-facing results.
